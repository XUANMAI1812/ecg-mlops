# ecg-mlops

Hệ thống phân loại ECG đa nhãn (5 superclass của PTB-XL) kèm nền tảng MLOps vận hành
mô hình. Đồ án học thuật; không phải thiết bị y tế và không dùng để chẩn đoán thật.

- Hướng dẫn cài đặt môi trường và tái tạo bước khảo sát dữ liệu: [docs/setup.md](docs/setup.md)
- Dữ liệu: PTB-XL v1.0.3 (PhysioNet, giấy phép CC BY 4.0)
